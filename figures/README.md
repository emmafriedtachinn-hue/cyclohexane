# Figures

Store screenshots, plots and process diagrams that support the engineering discussion.

Suggested subfolders:

~~~text
figures/
├── original-process/
├── flowsheet/
├── reactor/
├── separation/
├── recycle/
├── distillation/
└── sensitivity/
~~~

Only keep figures that explain a result, decision, convergence issue or final design feature.

Examples:

- original process flow diagram
- DWSIM flowsheet milestones
- reactor outlet-temperature tests
- E-200 phase-state comparison
- flash-composition results
- shortcut-column results
- rigorous-column profiles
- sensitivity plots
