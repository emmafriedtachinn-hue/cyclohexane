- national occupational-safety agencies for benzene, hydrogen and cyclohexane

- major accident investigation reports
- HSE / equivalent process-safety case studies

## Literature-management rule

For every parameter that materially affects the final design, record:

1. source
2. publication date
3. process/catalyst context
4. value or conclusion used
5. whether it is directly transferable to this model
6. uncertainty / limitation

A source should not be cited simply because it contains the same chemical name; the operating regime and technology must be relevant.
